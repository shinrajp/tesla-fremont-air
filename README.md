# Air near Tesla Fremont

Live PurpleAir PM2.5 AQI map for the sensors around Lila Bringhurst Elementary, the Innovation community and the Tesla Fremont Factory.

- `data.json` refreshes every 20 minutes, `history.json` (last 72 h) at most hourly.
- Source: PurpleAir.com public sensors, raw readings (same as the PurpleAir map), converted with the US EPA 2024 PM2.5 AQI breakpoints.
- Open a sensor's card directly: `?open=322702`. Pick the map average: `?w=10minute|60minute|24hour`.
